# Автоматическое ценообразование для Wildberries и Ozon

Данный проект представляет собой асинхронную систему на Python для автоматического расчета и обновления цен на маркетплейсах Wildberries и Ozon. Система учитывает закупочную стоимость, целевую прибыль, комиссии, логистику (включая возвраты), а также автоматически повышает цены перед акциями и блокирует их на время проведения.

## Основные возможности

### Общие для обоих маркетплейсов
- Расчет целевой цены на основе закупочной цены, целевой прибыли, комиссий и логистики.
- Учет НДС (ставка настраивается).
- Сбор статистики по доставкам и возвратам для точного расчета средней логистики.
- Обработка товаров с продажами и без продаж раздельными модулями.
- Подробное логирование всех действий в консоль и базу данных.
- Автоматическая очистка устаревших записей в БД.
- Управление акциями: повышение цены перед акцией, блокировка во время акции, возврат после окончания.

### Для Wildberries
- Получение заказов через API статистики.
- Расчет логистики по габаритам товара с использованием тарифов конкретного склада.
- Для товаров с продажами – средневзвешенная логистика с учетом возвратов (фиксированная стоимость возврата, настраиваемая).
- Для товаров без продаж – расчет по тарифам склада, с которого были последние отгрузки, или дефолтным значениям.
- Поддержка скидок продавца (wb_seller_discount).

### Для Ozon
- Получение заказов через Ozon Seller API.
- Расчет логистики через СДЭК по габаритам и региону доставки.
- Для товаров с продажами – средняя логистика с учетом возвратов (процент от стоимости доставки).
- Для товаров без продаж – упрощенный расчет: цена = закупочная × множитель (настраивается).
- Учет скидок продавца (ozon_seller_discount).

## Архитектура

Проект организован модульно:
- `WB_integration/` – модуль для Wildberries.
- `OZON_integration/` – модуль для Ozon.
- `config.py` – загрузка конфигурации из .env и таблицы настроек БД.
- `run_all.py` – главный оркестратор, запускающий все модули в отдельных задачах с защитой от конфликтов.
- `db_cleanup.py` – автоматическая очистка устаревших данных.

Каждый модуль содержит:
- `api/` – клиенты для работы с API маркетплейсов (WB, Ozon, СДЭК).
- `core/` – основные классы обновления цен (с продажами и без).
- `structures/` – dataclasses для данных.
- `utils/` – вспомогательные функции (логирование, расчеты).

## Основные компоненты

### 1. Конфигурация
Все настройки хранятся в `.env` и дублируются в таблице БД `oc_auto_price_settings` для возможности изменения через админку. Загрузка происходит в `config.py`.

### 2. Оркестратор (`run_all.py`)
Запускает независимые модули:
- WB с продажами
- WB без продаж
- Ozon с продажами
- Ozon без продаж
- Фоновые задачи очистки БД и синхронизации акций

Модули без продаж не запускаются одновременно с модулями с продажами того же маркетплейса (защита от конфликтов).

### 3. Расчет логистики для Wildberries
- Используется средневзвешенный тариф по всем складам (на основе статистики заказов за 14 дней) или конкретный склад для товара.
- Для каждого заказа определяется склад и рассчитывается стоимость доставки.
- Ведется таблица `oc_wb_logistics_stats` с накоплением данных по каждому товару и складу.

### 4. Расчет логистики для Ozon
- Для товаров с продажами собирается статистика по регионам (`oc_ozon_logistics_stats`).
- При расчете цены сначала проверяется наличие средней логистики из статистики, иначе – рассчитывается по текущим заказам.
- Возвраты учитываются через процент от стоимости доставки.

### 5. Акции
- Менеджеры акций (`promotions_client.py` и `promotions_client_wb.py`) получают предстоящие акции из API.
- Для каждого товара с продажами создается план повышения цены с безопасным дневным лимитом.
- Во время акции цена блокируется, после – восстанавливается.

### 6. Логирование
- Два файла `database_logger.py` (для Ozon и WB) обеспечивают запись всех событий в таблицу `oc_price_updater_logs`.
- Поддерживаются специализированные методы для разных типов событий: расчет цены, пропуск, ошибка, акции, вызовы API и т.д.
